# Empty Shader IDE project

A blank project with no effects. Copy this folder, change `name` and `author` in `project.json`,
then open the folder in Shader IDE and add effects from the gallery or with New Effect.

- `project.json` holds the pack's name, author, namespace, seed and effect list.
- `effects/` holds each effect's `.glsl` file. Add a `NAME.variants.glsl` template here to make many effects at once.
- Build settings go in `build.json` if you want to change them (see the Learn lessons).
